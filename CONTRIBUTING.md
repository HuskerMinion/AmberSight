# Contributing to AmberSight

Thank you for helping make AmberSight better. Bug reports, ideas and code are
all welcome.

## Reporting a problem

Open an issue and include what you expected, what happened, your operating
system, and the AmberSight version (Settings > System > Status & updates).
Please leave out passwords, camera addresses and other private details.

## Sending changes

1. Keep each change focused on one thing, and explain why it is needed.
2. Run `cargo build --release` (no warnings) and `cargo test` before sending.
3. For changes to the web interface, check it in a desktop browser and on a
   phone-sized screen, in both the light and dark themes.
